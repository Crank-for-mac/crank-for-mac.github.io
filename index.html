Automate Effortlessly

Crank lets you create powerful automations using simple natural-language rules. Respond to events on your Mac—apps launching, files changing, windows moving—with actions like file management, window control, or custom scripts. Everything runs locally, privately, and in the background.

Natural-Language Rules

Write rules in plain English: "When Safari opens, move Downloads to Desktop." Crank interprets and executes them instantly, no coding required.

Event-Based Triggers

Monitor apps, files, folders, windows, clipboard changes, and system events. Build responsive automations that adapt to your workflow in real time.

Precise Actions

Move files, resize windows, run shell scripts, AppleScript, Swift, or custom binaries. Syntax highlighting and compilation checks ensure reliability.

Private and Extensible

Local execution keeps your data secure. Extend with zsh, Python, Ruby, Perl, Swift, or any binary. Headless mode hides the menu bar icon for seamless operation.

How It Works

Step 1: Define Your Rule

Open Crank and write a natural-language rule describing the trigger and action, like "If a file is added to Downloads, archive it."

Step 2: Choose Triggers

Select from apps, files, windows, clipboard, or system events. Fine-tune with conditions for precision.

Step 3: Set Actions

Pick file operations, window management, clipboard tasks, or scripts. Use the picker for shell, Swift, and more with syntax highlighting.

Step 4: Activate and Monitor

Rules run in the background. Get notifications for errors; edit anytime. Fully headless option available.
